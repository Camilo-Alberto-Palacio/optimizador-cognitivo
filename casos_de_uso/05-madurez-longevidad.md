# Caso de Uso 05: Adulto Mayor (Longevidad y Prevención Cognitiva)

**Perfil:** Persona de 65+ años interesada en biohacking para la longevidad.
**Situación:** Prevención del declive cognitivo leve y mantenimiento de la autonomía mental.

## 🔴 El Desafío
La reducción natural de la neurotransmisión y la sensibilidad a la inflamación. El usuario necesita un sistema "amigable" pero potente para monitorear su estado diario.

## 🛠️ Cómo Ayuda Quantum Bio-Engine
1.  **Accesibilidad Inclusiva:** El usuario activa el **Modo de Alto Contraste** y **Fuente Grande (Aa)** en el menú "Tú" para una lectura sin esfuerzo.
2.  **Monitoreo de SpO2:** Crítico en esta edad para detectar hipoxia nocturna que causa confusión mental. El sistema genera alertas visuales claras.
3.  **Registro de Suplementos Preventivos:** Seguimiento de **Omega-3 (DHA)**, **B12** y **Vitamina D3**, asegurando que no se olviden las dosis diarias.
4.  **Establecimiento de Baseline:** El usuario realiza el test de CI base para tener una referencia histórica y detectar caídas inusuales que podrían indicar fatiga o desequilibrio nutricional.

## 💡 Recomendaciones del Sistema
-   *Caminatas en Zona 2:* El sistema sugiere caminar al menos 7,000 pasos para oxigenar el cerebro.
-   *Socialización:* Se recomienda registrar eventos sociales como "impacto positivo" en el bienestar mental.
